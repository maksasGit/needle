# Чеклист 2D-графики, типографики и текстов

Живой список для текущей игры. Стиль — [ART_DIRECTION.md](ART_DIRECTION.md): яркие игрушечные формы, крупные пиктограммы, короткие подписи, тёмная обводка. Смежные списки: [3D](ASSETS_3D.md), [звук](AUDIO_ASSETS.md).

`[x]` — готово и подключено с базовой проверкой; `[ ]` — создание/доработка финальной версии. Пометка «есть прототип» означает, что рабочий интерфейс уже существует: не создавать его заново. **P0** — основной цикл, **P1** — оформление текущих функций, **P2** — необязательная полировка/материалы публикации. Этот список не поручает немедленную реализацию всех пунктов.

## Общие требования

Рекомендуемые качество, размеры и память по TYPE/ICON/UI/TEXT/TUT/FX/PUB: [ASSET_BUDGETS.md](ASSET_BUDGETS.md). Цель runtime UI — до 0,5 МиБ файлов и до 4 МиБ резидентных растровых изображений; шрифты/DOM измеряются отдельно. Общие иконки и CSS-состояния переиспользуются, обложки/баннеры не входят в игровой runtime. При поставке фиксировать формат, размер, разрешение и переиспользование.

Предпочитать SVG, HTML/CSS и общие стили; PNG/WebP — только там, где нужен растр. Не генерировать картинку для каждого состояния простой кнопки. Иконки должны читаться при 24–32 px, интерактивная область — не меньше 44×44 CSS px. Учитывать safe areas, портрет/альбом и reduced motion. Текст не запекать в изображения: нужны русский и английский, доступные подписи и устойчивость к разной длине строк.

## Обновление списка

Новый экран, кнопка, иконка, эффект, шрифт или группа текстов должны получить пункт до/вместе с реализацией. Указывать ID, приоритет, назначение, текущий статус, фактический путь после интеграции. Для покупных/внешних шрифтов и изображений дополнительно обновлять `ASSET_LICENSES.md`. Не заводить дубликат, если можно расширить существующий элемент.
