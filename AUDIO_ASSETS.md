# Чеклист музыки и звуков

Живой аудиоплан Needle in a Haystack. Смежные списки: [3D](ASSETS_3D.md), [2D](ASSETS_2D.md). Сейчас звуков, музыки и AudioManager в игре нет: все пункты ниже открыты. Это план производства для существующих механик, а не утверждение о готовом аудио.

`[x]` — файл/синтез подготовлен, подключён и базово проверен; `[ ]` — требуется работа. **P0** — основные действия, **P1** — окружение и полный набор текущих механик, **P2** — необязательная полировка. Не начинать массовую генерацию или закупку звуков без отдельной задачи.

## Общая звуковая палитра и поставка

Тёплая, лёгкая, игрушечная ферма: мягкие деревянные удары, сухой шелест сена, короткие мелодичные награды. Без резких криков, взрывов, навязчивых сигналов, громкого саббаса и реалистичной тяжёлой техники. Не копировать мелодии, узнаваемые звуки франшиз и чужие записи с неизвестными правами.

Для изготовления хранить чистые WAV-мастера отдельно от поставки; в игру включать компактный поддерживаемый браузерами формат. Короткие эффекты обычно mono, музыка/фон — stereo при реальной пользе. Обрезать тишину, избегать клиппинга, бесшовно сводить loops. Формат и громкость проверять в целевых браузерах; не добавлять все возможные кодеки без необходимости.

Ориентиры длительности ниже — художественные, не обязательные лимиты. Генерировать 2–4 варианта частых звуков только когда это уменьшает повторяемость, а не ради числа файлов. Звуки не должны задерживать действие или первую интеракцию.

## Музыка и атмосфера

- [ ] **AUD-MUS-01 · P1 · Основной фоновый саундтрек.** Спокойная доброжелательная инструментальная петля примерно 60–120 с: лёгкие щипковые/деревянные тембры, ненавязчивая мелодия, место для игровых эффектов. Без вокала и нарастающего давления; комфортно при долгом повторении, мягкое бесшовное соединение.
- [ ] **AUD-AMB-01 · P1 · Воздух фермы.** Тихий ветер и мягкое движение листвы, петля 20–40 с без заметных повторных событий. Не должен звучать как постоянное шипение поверх соломы.
- [ ] **AUD-AMB-02 · P2 · Редкие птицы.** Несколько коротких дружелюбных чириканий с длинными непредсказуемыми паузами. Не спамить и не маскировать подсказки; отдельные голосовые/животные персонажи в игру не добавляются.
- [ ] **AUD-MUS-02 · P1 · Фанфара победы.** Короткое 2–4-секундное завершение в той же тональной палитре, с мягким затуханием музыки. Может быть одним ассетом с `AUD-OBJ-03`, чтобы не складывать две фанфары.

## Сбор и перенос сена

- [ ] **AUD-HAY-01 · P0 · Начало хвата рукой.** Мягкий короткий взмах/касание, около 0,1–0,25 с. Отдельный необязательный акцент до завершения сбора; при отмене не проигрывать звук успешной добычи.
- [ ] **AUD-HAY-02 · P0 · Успешный сбор руками.** Сухой приятный «шурх» отделяемой соломы, 0,15–0,35 с, 3 варианта. Запуск только когда сено действительно попало в инвентарь.
- [ ] **AUD-HAY-03 · P0 · Сбор граблями.** Чуть более широкий шелест с мягким скребком зубьев, без неприятного металлического писка. Короткий вариант для высокой скорости прокачки.
- [ ] **AUD-HAY-04 · P1 · Сбор вилами.** Короткий вход зубьев и объёмный подхват сухого сена; отличается от грабель тембром, а не только громкостью.
- [ ] **AUD-HAY-05 · P1 · Сбор широкими вилами.** Более широкий подхват сена, но умеренная громкость; можно получить из того же семейства записей, не обязательно новый большой файл.
- [ ] **AUD-HAY-06 · P1 · Локальное осыпание стога.** Тихий каскад сухих соломинок, 0,2–0,6 с. Один ограниченный эффект на локальное осыпание, не звук на каждую из 20 000 соломинок.
- [ ] **AUD-HAY-07 · P2 · Движение переносимого сена.** Очень тихий краткий шелест при изменении груза/позе; не непрерывная петля поверх каждого шага. Использовать только если улучшает ощущение переноски.
- [ ] **AUD-HAY-08 · P0 · Инвентарь заполнен.** Мягкое различимое подтверждение один раз при достижении лимита. Не повторять раздражающий сигнал на каждом неверном тыке.

## Телега, продажа и покупки

- [ ] **AUD-CART-01 · P0 · Выгрузка груза.** Мягкое падение сена на деревянный кузов с шелестом, 0,3–0,7 с. Один звук на операцию или короткая ограниченная серия, не по звуку на каждую соломинку.
- [ ] **AUD-CART-02 · P1 · Деревянный отклик кузова.** Негромкий короткий «тук»/скрип под весом груза. Может быть слоем `AUD-CART-01`; сама телега сейчас не ездит, петля катящихся колёс не нужна.
- [ ] **AUD-ECO-01 · P0 · Начисление монет за продажу.** Короткий светлый звон/мелодичный каскад, 0,2–0,5 с. Звучит при фактической немедленной выплате; количество звуков не равно количеству монет.
- [ ] **AUD-ECO-02 · P0 · Успешная покупка улучшения.** Позитивный двухнотный акцент с мягким щелчком, отличимый от продажи. Один раз на успешную покупку, не при открытии карточки.
- [ ] **AUD-ECO-03 · P1 · Появление нового инструмента.** Короткий деревянно-металлический акцент смены модели. Согласовать с покупкой, чтобы не проигрывать два громких результата одновременно.
- [ ] **AUD-ECO-04 · P1 · Покупка недоступна.** Тихий нейтральный низкий щелчок при недостатке монет; без тревожной ошибки и навязчивого призыва купить валюту.
- [ ] **AUD-ECO-05 · P2 · Достигнут максимум улучшения.** Короткое спокойное подтверждение при достижении последнего уровня. Не нужен отдельный файл, если подходит вариация успешной покупки.

## Ходьба, прыжок и приземление

- [ ] **AUD-MOVE-01 · P0 · Шаги по траве.** 3–4 коротких приглушённых шага с мягким шуршанием; темп связан со скоростью движения. Не звучат в покое, при упоре в препятствие без фактического движения и в воздухе.
- [ ] **AUD-MOVE-02 · P1 · Шаги по земле.** Более сухой мягкий удар без каменного эха; для вытоптанной площадки, если различение материала поверхности будет подключено.
- [ ] **AUD-MOVE-03 · P0 · Шаги по стогу.** Сминаемая сухая солома с мягким низом, 3 варианта. Для уже существующей ходьбы по сену, без скрипа снега/хруста костей.
- [ ] **AUD-MOVE-04 · P0 · Отталкивание при прыжке.** Очень короткий шаг/лёгкий свист воздуха, без обязательного голоса персонажа. Только успешный прыжок с опоры, не повторные нажатия в воздухе.
- [ ] **AUD-MOVE-05 · P0 · Приземление на землю/траву.** Мягкий глухой контакт и немного шелеста. Громкость ограничена; падение со стога не должно звучать как получение урона, которого в игре нет.
- [ ] **AUD-MOVE-06 · P0 · Приземление на сено.** Более объёмный мягкий «фшух», 0,2–0,4 с. Согласовать с осыпанием, чтобы не суммировать несколько одинаковых событий.

## Иголка и обучение

- [ ] **AUD-OBJ-01 · P1 · Иголка открылась после разбора стога.** Лёгкий серебристый блик-звон, 0,4–0,8 с, один раз на обнаружение. Не выдаёт скрытую иголку постоянным звуковым маяком с начала игры.
- [ ] **AUD-OBJ-02 · P0 · Подбор иголки.** Чистый короткий металлический/мелодичный акцент, отличимый от монеты; подтверждает реальный подбор.
- [ ] **AUD-OBJ-03 · P0 · Победа.** Тёплая короткая музыкальная награда без резкого всплеска громкости. Переиспользовать `AUD-MUS-02`, если это один общий момент.
- [ ] **AUD-TUT-01 · P1 · Новый шаг обучения.** Тихий короткий «поп» появления указателя; один раз на шаг, не на каждый пульс рамки.
- [ ] **AUD-TUT-02 · P1 · Шаг обучения выполнен.** Мягкое подтверждение; при сборе/покупке можно использовать их существующий звук вместо наложения ещё одного.

## Интерфейс

- [ ] **AUD-UI-01 · P0 · Нажатие обычной кнопки.** Короткий упругий щелчок, 0,05–0,15 с; одна общая запись/синтез для клика и касания, без обязательного hover-звука.
- [ ] **AUD-UI-02 · P1 · Открытие магазина/настроек/помощи.** Негромкий лёгкий переход, 0,1–0,2 с. Можно переиспользовать один ассет на все панели.
- [ ] **AUD-UI-03 · P1 · Закрытие/назад.** Более короткий обратный акцент того же семейства.
- [ ] **AUD-UI-04 · P1 · Переключатель настройки.** Мягкие варианты вкл./выкл., без мешающего демонстрационного звука после отключения всех звуков.
- [ ] **AUD-UI-05 · P1 · Невозможное действие.** Тихий нейтральный щелчок для «слишком далеко/нечего продать», с ограничением частоты. Сначала проверить, не достаточно ли визуальной обратной связи.

## Задачи подключения аудио — не отдельные звуковые файлы

- [ ] **AUD-SYS-01 · P0 · AudioManager и разблокировка браузером.** Запуск только после допустимого пользовательского жеста; ошибки загрузки/декодирования не останавливают игру. Музыка и эффекты не блокируют первую интеракцию.
- [ ] **AUD-SYS-02 · P0 · Громкость и отключение.** Отдельное управление музыкой и эффектами, сохранение предпочтений локально; понятные состояния кнопок из `2D-ICON-16`. Игра полностью понятна без звука.
- [ ] **AUD-SYS-03 · P0 · Пауза и очистка ресурсов.** При скрытой вкладке/паузе звук не продолжает неожиданно играть; корректное возобновление, остановка источников и освобождение ресурсов при перезапуске.
- [ ] **AUD-SYS-04 · P0 · Ограничение повторов и голосов.** Пул источников, ограничение одновременных эффектов, небольшой pitch/volume-разброс частых действий. Особенно важно при сборе около 0,048 с: не создавать десятки громких хвостов каждую секунду.
- [ ] **AUD-SYS-05 · P1 · Баланс и мобильная проверка.** Проверить телефонный динамик/наушники, тихую громкость, портрет/альбом, фон/возврат, покупки и частый сбор. Избегать клиппинга и лишней загрузки памяти; фиксировать фактический размер аудионабора.
- [ ] **AUD-SYS-06 · P0 · Источники и права.** Для каждого файла или генератора записать автора, источник/сервис, разрешённое использование, атрибуцию и фактический путь в `needle-in-a-haystack/ASSET_LICENSES.md`. Не объявлять AI-файл автоматически свободным от ограничений.

## Обновление списка

При новой механике сначала определить, нужен ли новый звук или подходит имеющийся. Добавить ID, назначение, момент запуска, длительность/варианты и приоритет; после интеграции — путь и статус проверки. При замене записи обновить источник и удалить устаревшие ссылки. Новые персонажи/уровни не подразумеваются этим списком: их аудио добавляется после согласования соответствующей функции.
