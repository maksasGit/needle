# Промежуточный технический чек — 2026-11-13

**Это проверка текущего прототипа, не приёмка завершённой игры и не готовность к релизу.** По уточнению пользователя дальнейшие механики, баланс и игровые доработки остаются открытыми. ZIP не подготовлен, публикация не выполнялась.

## Что выполнено

Запущен `npm run verify`: TypeScript → проверки навигации и игровой логики → production build → проверка файлов сборки → Chrome/Playwright. Все команды завершились успешно.

Браузерный прогон использует установленный Chrome в headless-режиме и настоящий production-код, размещённый по вложенному URL. Настольные и сенсорные сценарии выполняются в изолированных профилях. Это не физический мобильный телефон.

В ходе исполнения согласованного плана уже добавлены: версионированные локальные сохранения, русский/английский язык, настройки уменьшенной анимации, новая игра с подтверждением, обнаружение/подбор иглы и экран победы. Это работающие части прототипа, а не утверждение о завершённости дизайна игры.

## Открыто и не считается проверенным

- Игровой дизайн, недостающие механики, темп прохождения и экономический баланс ещё дорабатываются. Увеличение стога до 10 000 соломинок само по себе не подтверждает подходящую длительность игры.
- Не проверены реальные Android/iOS-устройства, Safari и длительный прогон на средних мобильных GPU. Эмуляция touch не заменяет эти проверки.
- Не измерены производственный crash rate, реальная мобильная загрузка, пиковая GPU-память и многочасовая стабильность.
- Нет аудио: настройки звука и проверка аудио-жизненного цикла пока неприменимы.
- Локальный iframe не доказывает работу после загрузки на itch.io: ограничения хранилища и поведение конкретного браузера в iframe нужно проверять на площадке позже.
- Внешние игровые арт-ресурсы не используются; происхождение и лицензии зависимостей описаны в [ASSET_LICENSES.md](../ASSET_LICENSES.md). Это запись происхождения, не юридическая экспертиза.
- Изменение баланса/формата сохранений в следующих механиках потребует миграции или явной обработки несовместимого формата. Сейчас поддерживается версия 1.

## Повторение чека

Из `needle-in-a-haystack/`: `npm run verify`. Для браузерного прогона нужен установленный Chrome; Playwright — только dev-зависимость. `npm run check:build` проверяет лимиты и относительные пути, копирует лицензию Three.js и записывает отчёт. `?diagnostics` включает только чтение диагностических данных, без команд изменения игры.

### Уплотнение соломинок

Опорный шаг колонок уменьшен на 25% (`contactScale: 0.75`, эффективный шаг 0,045 вместо 0,06). Отдельных физических хитбоксов соломинок нет; допускается визуальное пересечение при более плотной укладке. Размер геометрии и точность выбора лучом сохранены. Старые сохранения уплотняются по высоте без сброса прогресса; новый коэффициент записывается в сохранение. Тесты миграции, количество соломинок, TypeScript, production build и браузерный прогон прошли; таблица выше отражает обновлённый прогон.


### Вечернее освещение и контур выбора

Окружение затемнено, сено выделено тёплым светом. Вместо заливки выбранная соломинка получила светлый мятный контур с тёмной каймой. Контур виден целиком поверх соседних соломинок, без постобработки всей сцены. Результат осмотрен на скриншотах desktop и target-outline; TypeScript, тесты, сборка и полный браузерный прогон прошли. Таблица измерений обновлена по JSON-отчётам.

Стог увеличен до 20 000 соломинок. Вместимость: 15 покупок, максимум 80; скорость сбора: 10 покупок, минимум около 0,048 с. Стоимость ранних покупок сохранена, поздняя вместимость дорожает плавнее. ### Ручная ходьба и джойстик — 2026-11-13

По уточнению пользователя движение по клику удалено. На ПК ходьба управляется WASD/стрелками, обзор — перетаскиванием мышью. На телефоне экранные стрелки заменены аналоговым джойстиком (мёртвая зона 12%) и независимым touch-обзором. Земля игнорирует клики; дальние стог, телега и игла не запускают маршрут и не взаимодействуют. Браузерные сценарии теперь действительно подходят к объектам клавишами или джойстиком. Проверены два касания, отпускание, touch cancellation, меню, сохранение и перезапуск. Все 19 браузерных сценариев прошли без ошибок страницы/ресурсов, TypeScript и тесты прошли. Физический телефон этим не заменяется.
