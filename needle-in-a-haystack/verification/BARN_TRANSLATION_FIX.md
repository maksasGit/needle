# Ошибка после изменения текстов — 2026-11-17

По присланному логу подтверждён `ReferenceError: t is not defined` в EconomySystem.barnOffer для рюкзака/свинки. При незакоммиченном обновлении форматирования был удалён импорт t, но два вызова остались. Отрисовка атласа обрывалась после четырёх инструментов; последующее наведение на предмет приводило к перехвату ошибки игрового цикла.

Исправление: явный отдельный импорт `t as offerText` для двух названий предложений. Он не зависит от списка импортов числового форматирования. Дополнительно PCFSoftShadowMap заменён на PCFShadowMap, который Three.js уже автоматически выбирал с предупреждением. Это предупреждение не было причиной остановки.

Сохранения/экономика не менялись, сброс прогресса не требуется. Незакоммиченные изменения текстов и интерфейса сохранены и не включены в отдельный коммит исправления. Проверен исходник и diff; тесты, typecheck, build, запуск браузера и скриншоты не выполнялись по текущему workflow. Нужна ручная перезагрузка и проверка продолжения, табличек рюкзака/свинки и наведения на них.
