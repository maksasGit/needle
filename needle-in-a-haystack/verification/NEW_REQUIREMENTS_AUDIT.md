# Аудит новых требований: стиль, первый запуск и обучение

Дата: 2026-11-13. Основание: раздел 17 корневого `AGENTS.md`.

**Прототип соответствует новым требованиям частично. Основные пробелы — интерактивное обучение, трёхфазная загрузка и яркий дружелюбный визуальный стиль. Цель 3 секунд не подтверждена на реальном телефоне и неустойчива в проверенной эмуляции.** Это аудит промежуточного прототипа, не релизная приёмка.

Игровой код, баланс, стиль и управление в рамках этого аудита не изменялись. Добавлен воспроизводимый инструмент измерения `npm run audit:first-load`, JSON-отчёт и скриншоты.

Свежие проверки TypeScript, тесты логики, production build и лимиты сборки прошли. Повторный обычный браузерный прогон: 19 сценариев прошли, ошибок страницы и загрузки ресурсов нет. Отдельный startup-аудит выполнил 9 запусков без ошибок; успешное выполнение измерений не означает выполнения цели 3 секунд.

## Проверка первого запуска

Production-сборка запускалась с холодным HTTP-кэшем: новый браузерный контекст на каждый прогон, кэш отключён через CDP, Service Worker обходится. Тестовый сервер отдаёт gzip. Три прогона на профиль, экран 390×844 с touch и DPR 2. Использован установленный Chrome в headless-режиме.

| Профиль | Условия | Первый кадр, медиана | Подтверждённая ходьба, медиана | Первый сбор, медиана |
| --- | --- | --- | --- | --- |
| Локальный холодный запуск | Без ограничения сети и CPU | 0,56 с | 0,75 с | 2,38 с |
| Условно мобильный | 1,6 Мбит/с, задержка 150 мс, CPU ×4 | 2,93 с | 3,31 с | 4,89 с |
| Ограниченная сеть | 0,4 Мбит/с, задержка 400 мс, CPU ×6 | 6,87 с | 7,55 с | 9,23 с |

В условно мобильном профиле первый кадр получен за 2,79–3,06 с: один из трёх прогонов вышел за 3 секунды. Ходьба наблюдалась за 3,07–3,42 с, первый сбор — за 4,70–5,23 с. Сам первый кадр не доказывает готовности к полезному действию.

Методические ограничения: время считается от начала навигации; подтверждение движения включает накладные расходы автоматизации и проверки состояния. Первый сбор также включает ручное перемещение джойстиком из стартовой точки и длительность сбора. Это не изолированный замер задержки обработчика ввода. CPU ×4/×6 — замедление относительно данного компьютера, а не модель конкретного телефона. Три прогона не дают статистики реальных пользователей. Эти данные не заменяют реальное устройство и сеть itch.io.

Начальный ответ содержит 159 573 байта сжатых тел ресурсов (около 156 КиБ), около 161 073 байт с учётом измеренных transferSize. После распаковки — 617 137 байт. Запрашиваются HTML, CSS и все три JS-части до первого кадра. Полный каталог сборки, включая лицензию, — 618 228 байт, 6 файлов; крупнейший файл — 352 560 байт. Лимиты размера соблюдены, но небольшой объём загрузки сам по себе не обеспечивает быстрый старт.

Зафиксированы длинные задачи: максимум 275–388 мс на локальных прогонах, 1264–1454 мс при CPU ×4 и 1950–2432 мс при CPU ×6. Данные показывают проблему синхронного запуска; конкретный вклад генерации стога, компиляции шейдеров и прочих операций требует отдельного профилирования, а не предположений.

Исходные данные: [first-load/report.json](first-load/report.json). Скриншоты: [portrait](first-load/local-cold-portrait.png), [landscape](first-load/mobile-like-4g-landscape.png).

## Проверка последовательности обучения

| Шаг | Есть сейчас |
| --- | --- |
| 1. Подсветить стог как первую цель | Нет; выделяется только отдельная соломинка под прицелом |
| 2. Научить подойти и нажать | Нет указателя движения или жеста; есть текст «Подойди к стогу» |
| 3. Показать сбор | Анимация есть, но шагом обучения не управляется |
| 4. Подсветить телегу | Нет направляющего выделения |
| 5. Направить сено к продаже | Ручная ходьба и продажа работают, обучения нет |
| 6. Показать награду монетами | Счётчик и статус есть, анимации монет нет |
| 7. Выделить первое доступное улучшение | Магазин включает доступную кнопку, но не выделяет нужное улучшение и не направляет к ней |
| 8. Провести покупку | Покупка работает, отдельного шага нет |
| 9. Продемонстрировать улучшение | Эффект работает; управляемой демонстрации нет |
| 10. Ввести цель с иглой | Цель сразу написана в названии/статусе; последовательного введения после улучшения нет |

**Зависимость экономики:** одна соломинка даёт 1 монету, первая вместимость стоит 5. Если после единственного сбора сразу направить игрока продавать и покупать, покупка окажется недоступна. Для будущего обучения подходит сбор и продажа полных рук (5), с визуальным заполнением пяти ячеек. Это предложение дизайна, не внесённое изменение механики или цен.

Подход к объектам должен оставаться ручным: джойстик/клавиши → попадание в радиус → нажатие. Обучение не должно возвращать автоподход.

## Приоритет доработок

1. **Первое действие:** профилировать синхронный запуск, оптимизировать создание обязательного стога, отложить декор, неиспользуемые инструменты и прочий некритичный контент до интерактивности. Перемещение тяжёлого конструктора сразу после первого кадра тоже может заморозить игру, поэтому нужны ограниченные фоновые порции работы и замеры.
2. **Обучение:** один визуальный шаг за раз — движение к стогу, заполнение первых пяти ячеек, телега, награда, первая вместимость, демонстрация результата, цель с иглой. Переходы по успешным игровым действиям; повтор и завершение сохраняются локально, учитывается reduced motion.
3. **Стиль и читаемость:** привести сцену к новому яркому направлению, сохранить контраст сена и контур выбранной соломинки; уменьшить визуальный шум теней и текстовую нагрузку. Не добавлять тяжёлые украшения в критический путь.
4. **Обратная связь:** визуальная награда монетами и демонстрация первой покупки; начисление остаётся мгновенным, анимация не меняет экономику.
5. **Валидация:** повтор холодного запуска и ограниченной сети, физические устройства Android/iOS, наблюдаемый плейтест с целевой аудиторией, затем проверка внутри настоящего itch.io iframe.

## Ограничения проверки

- Физические телефоны, дети 5–12 лет и настоящий itch.io-хостинг в этой проверке не использовались. Возрастную доступность и релизную готовность не подтверждаю.
- Работающая справка не считается интерактивным обучением. Отсутствующие шаги нельзя объявить протестированными.
- Холодный HTTP-кэш не означает холодные системные дисковые кэши или отсутствие внутренних кэшей шейдеров между браузерными контекстами.
- Размеры gzip зависят от тестового сервера; поведение CDN/сжатия itch.io проверяется отдельно.
- Локальный startup-бенчмарк не оценивает сам по себе многочасовую память или пиковую GPU-память. Отдельный технический регрессионный прогон описан в [AUDIT.md](AUDIT.md).

Повтор замеров: `npm run build && npm run check:build && npm run audit:first-load`. Подробные времена каждого из девяти запусков и длинные задачи находятся в JSON-отчёте, а не округлённой таблице.
