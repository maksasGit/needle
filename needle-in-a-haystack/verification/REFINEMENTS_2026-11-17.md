## 1. Активные таймеры

Game разделяет activeDt (реальный foreground elapsed) и dt≤50ms (стабильный шаг движения/осыпания/анимации). SaleEvent, ChestEvent, сбор, интервалы/возврат свинок и периодика сохранения получают activeDt. Меню/фон/WebGL loss сохраняют прежнее исключение времени через lifecycle resets. Удержание пылесоса не догоняет пропущенные действия пачкой: не больше одной команды при готовности, ручные клики не ставятся в очередь. Старые remaining/wait восстанавливаются без пересчёта/удвоения.

Telemetry gameSeconds остаётся legacy-счётчиком ограниченного физического шага, не authoritative timer clock. Контекст timing явно помечает foreground-wall для событий/сбора/свинок и capped-50ms для физики. Наблюдаемое eventSeconds клипуется остатком активного×2, чтобы длинный кадр не завышал экспозицию. Маркеры отчёта обновлены: build2026-11-17-refinements-r1 / revision foreground-time-shadow-proxy-pig-return-v1.

Проверено: компонентные deadlines90с/30с при шагах200ms; production-browser foreground stall1200ms уменьшил оба таймера более чем на1.1с, а не на50ms. Открытое меню не уменьшало таймер во время400ms ожидания.

## 2. Подготовка сохранения

Формат16bytes/соломинка и SaveData v9 сохранены. Углы квантуются со старым округлением, кешируются по stable ID. Обновляется только ограниченный набор движущихся соломинок. Snapshot использует переиспользуемый Int16 буфер и кеш неизменившейся base64-строки; кеш инвалидируется при remove, restore и вращении settling. Новая упаковка не создаёт20k временных массивов на каждый save. Поддерживаемый native toBase64 используется при наличии; fallback через UTF-16 code units сохраняет все byte0…255 без дорогих argument spreads/Windows1252 подмены.

Проверено побайтовое совпадение со старым encoder: полный стог, remove/swap, settling, restore и пустой стог. Быстрое арифметическое округление углов не оставлено: на half-boundaries оно могло отличаться от старого на1. Сохранён старый результат, ускорение получено кешированием.

Последний Node benchmark (8 запусков, медиана, не браузер/телефон): старый encoder20.54ms, новый некешированный4.10ms, кешированный≈0.0002ms. В production/headless первые два холодных snapshot всё ещё в среднем≈14–15ms, это другой runtime/нагрузка; нельзя объявить Node-ускорение доказанным для всех устройств. Повторная подготовка неизменившегося сена в браузерном сценарии≈0–0.1ms. Атомарность coins/hay/gems/meta и немедленная запись покупок/находок сохранены; перехода на другую базу/новой схемы saves нет.

## 3. Готовность сбора

CollectionFeedback создаёт один маленький RU/EN widget под прицелом: ✓Ready/Готово при доступном сене, полосу прогресса во время сбора. State transitions немедленные, progress до20Hz, одинаковые labels/DOM не переписываются повторно. В меню/фоне скрывается, dispose удаляет widget. Кнопки/мышь/касание, правило одного действия и молчаливые busy-команды прежние. В кадре нет очереди новых popup/звуков и CSS-мигания.

Проверено в production: ready→busy→одна собранная соломинка. Та же последовательность прошла касанием в портрете и после смены на альбом. Внешний вид на реальном экране ожидает владельца.

## 5. Свинки

Владелец подтвердил: скорость еды сокращает cooldown И порог обязательной прогулки. Старые3с умножаются на .9^speedLevel, как cooldown; скорость ходьбы/выбор маршрутов/порции/цены прежние. Таймеры и наблюдаемое время AI-состояний foreground-wall; движение остаётся capped physics. Текущие сохранённые уровни не сбрасываются.

В детерминированной flat-ground проверке actual PigHerd (одна свинка,600с, одинаковый seed/food point): base107 укусов, speedLevel3 —156. Это показывает действие ветки в конкретном синтетическом сценарии, **не реальный ROI/результат прохождения**. ECONOMY_CATALOG/exporter уточнены. Кандидат v2 не активирован, полный перебаланс цен не выполнялся.

## 7. Рендер

20k стеблей по-прежнему instanced, визуальная геометрия/подсветка/stable picking и поверхность ходьбы сохранены. Отдельная тень каждой соломинки/self-shadow отключены. Ground shadow даёт один hemisphere-proxy12×6 (132 геометрических треугольника); невидимый colour pass не пишет цвет/глубину. Масштаб тени выводится из оставшегося объёма, исчезает при пустом стоге. Осыпание без изменения proxy больше не запускает дорогой shadow-map update каждый кадр; remove/restore/прочие реальные изменения сцены сохраняют dirty updates.

В проверочной production-сцене full20k:≈243147 render triangles desktop и242545 touch. Это не сопоставимый FPS-бенчмарк со старыми игровыми JSON: камеры/SwiftShader другие. Архитектурно убран полный shadow pass по20k стеблей, а не только снижено число объектов JavaScript. Проверка художественного результата proxy-тени ожидается, screenshots не делались.
