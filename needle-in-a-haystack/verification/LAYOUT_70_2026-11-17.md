# Участок 70%: расстановка и UI

Владелец явно разрешил запуск игры, проверки и скриншоты **только для этой задачи**. Последующие задачи возвращаются к прежнему режиму без автоматических игровых проверок, если отдельно не запрошено.

## Изменения

- Стороны участка26→18,2единицы (70%прежней ширины/длины; площадь49%, а не70%). Ground, fence и границы ходьбы согласованы. Размеры моделей/стога/соломинок,20тысяч единиц сена и цены не уменьшались.
- Центры стога, иголки, телеги, амбара, колодца, доски, точки сундуков и локальные дорожки перенесены в более компактную схему. Дальние горы остаются прежними. Локальные декоративные предметы отфильтрованы из зон взаимодействия с учётом их размеров.
- Доска GLB повёрнута на180°: лист теперь обращён внутрь фермы. Убраны перекрывавшие подходы камень у доски и ящики у телеги. Не редактировалась геометрия исходных GLB.
- Инструменты/рюкзак у стойки получили удобные невидимые зоны выбора; по тонкой рукоятке больше не нужно попадать с точностью до пикселя. Свинка тоже имеет отдельную зону. Индивидуальная подсветка/выбор соломинок не менялись.
- Амбар получил сплошной навигационный footprint5,4×3,8 с его поворотом, чтобы игрок и питомцы не проходили сквозь закрытый корпус GLB. Стойка и предметы доступны снаружи.
- Радиус препятствия/взаимодействия телеги1,35→1,9 согласован с размером загруженной модели; продажа проверена с доступной позиции перед ней.
- Восстановлен скрывавшийся CSS-правилом значок алмазов в HUD. Индикатор сбора перенесён выше прицела, чтобы он не накладывался на подпись цели снизу.
- layoutVersion2: SaveSystem принимает старые координаты до±13; Game переносит игрока на новый spawn и масштабирует координаты выпавших алмазов для layout1. Сено хранится в локальных координатах и не пересоздаётся. Монеты, уровни, алмазы, таймеры и прогресс сохраняются.
- Отчёты теперь помечены `2026-11-17-compact-map-r2`, содержат layoutVersion/worldHalfSize и статусы загрузки трёх новых моделей. Схема save остаётся9.

## Проверки и ограничения

Проверялось в installed Chrome/headless SwiftShader: сначала dev, затем **production preview**. Desktop1366×900/1280×720, touch emulation390×844→844×390. Это не настоящий телефон, hardware GPU FPS, itch.io или измерение cold-cache сети.

Адресный сценарий `scripts/check-layout-70-browser.mjs` проверяет открытие UI через настоящие E/touch interactions, покупку инструмента, экипировку, покупку скорости персонажа и колодца, видимый отказ при недостатке монет, локальную/демонстрационную глобальную таблицу, прокрутку и смену ориентации. Есть проверка отсутствия наложения collection feedback/aim label, движения/прыжка/удержания пылесоса, мгновенной сдачи15сена→15монет и валидности сохранений после транзакций. Старое сохранение с position[12,12] загружается с переносом на[-3,5;0] без потери20тысяч сена.

- TypeScript и production build: прошли.
- `npm run check:build`: прошёл. Актуальные размеры — в build-report.json; около13,13MiB,21файл. GLB/музыка всё ещё превышают предпочтительные512KiB на файл, но ниже жёстких30MiB.
- `npm run test:refinements`: прошёл; данные последнего запуска в refinements-components.json. Синтетический Node benchmark не доказывает скорость телефона.
- `npm test`: навигация прошла; старый check-gameplay.mjs остановился на строке20 (`11 !== 5`). Он ожидает inventory5 после11сборов, хотя текущая исходная вместимость15. Это известные устаревшие ожидания R-01; весь старый набор **не прошёл**, несвязанные тесты здесь не переписывались.
- Итоговый browser-report и screenshots: [layout-70/report.json](layout-70/report.json). Никакой публикации не выполнялось.

## Осталось

- Ручная художественная приёмка владельцем и настоящий телефон. Модель доски имеет неровные/разорванные участки крыши: поворот исправлен, исходная геометрия не ремонтировалась.
- Стоимость декодирования2048²текстур и реальные FPS/нагрев на телефоне остаются отдельной оптимизацией.
- После сокращения расстояний времена старой и новой карты не строго сопоставимы. История рекордов сохранена, разделение по версии карты здесь не вводилось; размер карты теперь явно присутствует в playtest context.
- Пройти весь цикл на компактной карте, проверить долгую игру/питомцев и itch.io embed. Адресный UI-сценарий не равен полному прохождению.
